# Soundpack: NovelKeys Cream

- **Nhà sản xuất / Thiết kế**: NovelKeys / Kailh
- **Phân loại**: Full POM Linear Switch
- **Tác giả thu âm**: tplai (kbsim)
- **Giấy phép (License)**: [MIT License](https://github.com/tplai/kbsim/blob/master/LICENSE.md)
- **Nguồn gốc / Repository**: https://github.com/kamillobinski/thock-soundpacks/tree/main/keyboard/novelkeys/tplai/cream

## Giới thiệu & Đặc trưng âm thanh
Switch làm hoàn toàn từ chất liệu tự bôi trơn POM (polyoxymethylene), âm gõ clack độc nhất.

---
*Âm thanh được chuẩn hóa thành định dạng PCM WAV chất lượng cao dùng cho tính năng giả lập âm bàn phím cơ của bộ gõ MKey.*
